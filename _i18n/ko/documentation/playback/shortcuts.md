휴대전화나 태블릿에 물리('하드웨어') 키보드가 연결되어 있다면 몇 가지 단축키로 안테나팟의 재생을 제어할 수 있습니다. 볼륨과 음소거(해제) 동작은 (예를 들어 알림 채널이 아니라) 미디어 오디오 채널에 적용됩니다.

### 모든 화면(동영상 플레이어와 설정 제외)

| 키 | 동작 |
| --- | --- |
| `P` | 재생/일시 정지 |
| `J`/`A`/`,` | 뒤로 건너뛰기 |
| `K`/`D`/`.` | 앞으로 건너뛰기 |
| `+`/`W` | 볼륨 높이기 |
| `-`/`S` | 볼륨 낮추기 |
| `M` | 음소거/해제(전환) - Android 6 이상에서만 |

### 동영상 플레이어

| 키 | 동작 |
| --- | --- |
| `P`/`Space` | 재생/일시 정지 |
| `J`/`A`/`,` | 뒤로 건너뛰기 |
| `K`/`D`/`.` | 앞으로 건너뛰기 |
| `F`/`Esc` | 동영상 플레이어 나가기 |
| `i` | 화면 속 화면(PiP) 모드로 전환 |
| `0`-`9` | 동영상의 0~90% 지점으로 이동 |
| `+`/`W` | 볼륨 높이기 |
| `-`/`S` | 볼륨 낮추기 |
| `M` | 음소거/해제(전환) - Android 6 이상에서만 |
